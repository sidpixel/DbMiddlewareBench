⚡ 快速开始 (3 步)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第 1 步：安装依赖
  $ pip install -r requirements.txt

第 2 步：启动中间件 (选择一种方式)
  
  方式 A - Docker (推荐)
    $ docker-compose up -d
  
  方式 B - 手动启动
    $ redis-server              # 终端 1
    $ mongod                    # 终端 2
    $ mysql -u root -p          # 终端 3
    $ docker run -d -p 5672:5672 -p 15672:15672 rabbitmq:3-management  # 终端 4

第 3 步：运行压测
  
  方式 A - 命令行模式 (推荐新手)
    $ python benchmark_tool.py
    
    输出: 详细报告 + benchmark_results.json
  
  方式 B - Web 仪表板模式 (推荐高级用户)
    $ python app.py
    
    打开浏览器访问: http://localhost:5000

🎯 使用场景
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

场景 1：我想快速测试系统性能
  ➜ 使用 benchmark_tool.py (命令行模式)
  ➜ 查看报告了解各中间件的性能对比

场景 2：我想可视化地监控压测过程
  ➜ 使用 Flask Web 仪表板 (app.py)
  ➜ 在浏览器中实时查看结果

场景 3：我想定制化压测参数
  ➜ 修改 benchmark_tool.py 中的 main() 函数
  ➜ 修改 num_workers, operations_per_client 等参数

场景 4：我想添加新的中间件
  ➜ 阅读 ARCHITECTURE.md
  ➜ 继承 BenchmarkClient 类实现新客户端

❓ 遇到问题？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题                          解决方案
─────────────────────────────────────────────────────────────────────────────

连接被拒绝                    ➜ 检查中间件是否启动
                             ➜ 查看 README.md 中间件配置部分

Web 仪表板无法访问            ➜ 确保 Flask 后端正在运行
                             ➜ http://localhost:5000 是否可访问

内存溢出                      ➜ 减少 num_workers 参数
                             ➜ 减少 operations_per_client 参数

压测速度很慢                  ➜ 增加 num_workers (工作线程)
                             ➜ 检查网络连接质量
                             ➜ 检查中间件是否有资源限制
